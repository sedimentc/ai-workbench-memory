# 连接信息索引

本文件用于登记少数核心成员协作需要的电脑、服务器、公网入口和凭据位置。按照刘大当前口径，核心成员受限文档中可以记录必要账号、密码、API key、token 等真实协作凭据。

## 使用边界

- 本文件只给核心成员内部使用。
- 写真实凭据时，必须写明用途、负责人、风险级别、轮换规则。
- 非核心成员可见的文档仍应使用 `secret://...` 引用或写“走私密渠道”。
- GitHub 仓库如果设为公开或扩大成员范围，必须先清理本文件里的真实凭据。

## AI 处理规则

1. 用户明确要求记录真实凭据时，只能写入 `sensitivity: restricted` 且 `credential_allowed: true` 的文档。
2. AI 不得把真实凭据复制到普通 `internal` 文档、演示包、公开汇报稿或待审核提案。
3. 如果要引用凭据，优先写“见 `07_实战索引/连接信息索引.md` 的对应行”。
4. 如果凭据来自聊天或会议，必须补用途、负责人、风险级别后才能沉淀。
