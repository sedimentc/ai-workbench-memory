# 实战索引

本目录补齐刘大 MD 系统里最实用的一层：让 AI 能把用户的口语说法快速映射到页面、技能、项目、窗口、字段和连接信息。

## 固定检索顺序

AI 遇到模糊说法时，先按下面顺序查，不要直接全文阅读：

```text
用户口语 -> 别名词典 -> PAGE编号 / SKILL编号 / 项目ID / 窗口ID / 契约ID -> 子文档 -> 代码路径
```

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `别名词典.md` | 把“页面22”“小测”“上传 tf”等口语映射到标准对象 |
| `页面索引.md` | 页面编号、页面名、入口、项目和文档定位 |
| `项目索引.md` | 项目ID、项目名、仓库、页面范围和状态 |
| `技能索引.md` | 技能编号、触发说法、对应技能文档 |
| `窗口索引.md` | 第四级窗口索引字段和登记规则 |
| `字段契约索引.md` | API、数据库、运行数据的字段契约入口 |
| `连接信息索引.md` | 电脑、服务器、公网入口和凭据记录口径 |
| `最近改动索引.md` | 最近改动只放索引，不污染当前事实 |

## 读取边界

- 普通开发任务优先读 `别名词典.md`、`页面索引.md`、`项目索引.md`。
- 技能任务优先读 `技能索引.md`，再进入 `02_技能库/` 或具体 Skill 文档。
- 字段、接口、数据库任务优先读 `字段契约索引.md`。
- 第四级窗口、会话、电脑窗口任务优先读 `窗口索引.md`。
- 连接服务器、账号、密码、token 任务优先读 `连接信息索引.md`，并遵守 `00_规则/敏感信息规则.md`。
