# 窗口索引

窗口索引用来登记第四级对话窗口。第一阶段只定义字段和登记规则，真实窗口状态后续可由中心服务或 Dashboard 自动生成。

## 层级规则

```text
第一级：电脑，例如 computer0 / computer1
第二级：模型公司或工具，例如 Codex / Claude / 通义千问
第三级：项目或分组，例如 New Project
第四级：具体对话窗口，例如 AI 工作台-AP-新一
```

## 字段规范

| 字段 | 说明 |
| --- | --- |
| `fourth_level_id` | 第四级唯一 ID，优先等于真实 `window_id` |
| `computer` | 所属电脑 |
| `provider` | Codex、Claude 或其他模型工具 |
| `project` | 所属项目 |
| `third_level` | 第三级项目/分组 |
| `window_name` | 窗口名 |
| `status` | `running` / `idle` / `ended` / `unknown` |
| `related_pages` | 关联页面，如 `PAGE-21`、`PAGE-22` |
| `summary_doc` | 窗口摘要文档路径 |
| `updated_at` | 最后更新时间 |

## 使用规则

- 用户说“某个窗口”“第四级窗口”“电脑1上的 Codex 窗口”时，先查本文件。
- 找不到窗口时，AI 应要求用户补充电脑编号、模型工具、项目名、窗口名中的至少两个。
- 窗口摘要不能直接变成项目当前事实，必须经过待审核或人工确认。
