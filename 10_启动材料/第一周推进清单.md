# 第一周推进清单

## 目标

把共享 MD 系统从本地骨架推进到团队可试用状态。

## 第 1 天

- 陈纪言检查 `AI入口.md`、`总览.md`、AI 工作台 StartPack。
- 肖明确认 `02_技能库/README.md` 和技能库分工。
- 刘大/老王确认第一版边界：先 GitHub + MD，后中心服务。

## 第 2 天

- 创建 GitHub 仓库。
- 推送当前本地版本。
- 设置 main 分支保护。
- 测试 GitHub Actions 自检。

## 第 3 天

- 用一个新 AI 窗口只读 `AI入口.md`、`总览.md`、`StartPack.md`。
- 验证它能否 2 分钟内说清 AI 工作台状态。
- 记录问题到 `05_待审核/记忆提案/`。

## 第 4 天

- 肖明补第一批技能库候选。
- 陈纪言补资源登记缺失路径。
- 用 PR 模板走一次合并流程。

## 第 5 天

- 做一次 10 分钟演示。
- 展示新窗口接手、待审核提案、资源登记、自检脚本。
- 收集刘大和老王修改意见。

## 第一周验收

- 新窗口可以按入口接手。
- 自检脚本通过。
- 至少一个待审核提案跑通。
- 至少一个资源变更提案跑通。
- 肖明技能库能被总览和入口引用。
