# 给刘大汇报稿

刘大，我这边先把共享 MD 系统的第一版骨架搭出来了。

我的理解是，这个东西第一版不是直接做最终 AI 记忆中枢，而是先用 GitHub + Markdown 做一个可审核、可追溯、可被 AI 读取的协作记忆库。它吸收了你现在公共 MD 里的页面编号、项目记忆、敏感信息隔离规则，也吸收了王老师说的 StartPack、待确认记忆、证据层思想，同时兼容肖明的 GitHub 技能库方案。

我这边负责的是共享 MD 系统底座，主要包括：

- AI 新窗口入口。
- 总览导航。
- AI 工作台项目记忆。
- 当前状态和历史证据分离。
- 页面角标、端口、电脑环境、secret 引用登记。
- 待审核提案流程。
- 文档模板和自检脚本。

肖明负责技能库正文，比如程序提示词、前端页面复刻、DoneGuard 测试验收、API 开发规范这些。

第一版我没有把资源发号、窗口心跳、StartPack 自动生成做成中心服务，因为这块容易变复杂。现在先用 MD 和 GitHub 跑通协作流程，后续再把资源发号、窗口状态、待确认记忆面板迁移到中心服务。

当前可以演示的点：

- 新窗口读 `AI入口.md` 和 `StartPack.md` 接手项目。
- 页面编号规则和当前编号池。
- 待审核提案如何进入正式规则。
- 敏感信息不进文档，只写 secret 引用。
- 自检脚本能查重复 ID、疑似敏感信息、页面编号重复。

下一步我建议先拿 AI 工作台做样板，不急着全公司铺开。先让一个新 AI 窗口试着接手，看它能不能 2 分钟内说清当前项目状态。如果这个跑通，再让肖明补技能库第一批内容。
