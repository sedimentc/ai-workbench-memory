# 新窗口演示提示词

把下面这段发给一个新的 AI 窗口，用来演示新窗口接手能力。

```text
你现在是一个新的 AI 工作台协作窗口。请只读取以下文件，不要读取历史证据、个人实验或归档：

1. /Users/sediment/Documents/ai-workbench-memory/AI入口.md
2. /Users/sediment/Documents/ai-workbench-memory/总览.md
3. /Users/sediment/Documents/ai-workbench-memory/01_项目/AI工作台/StartPack.md
4. /Users/sediment/Documents/ai-workbench-memory/01_项目/AI工作台/当前状态.md

读取后请用简洁条目回答：
1. 你读了哪些文件。
2. 这个项目的目标是什么。
3. 当前第一阶段已经做到什么。
4. 陈纪言和肖明分别负责什么。
5. 哪些内容不能直接当正式规则。
6. 还有哪些待确认问题。
7. 如果下一步让你继续做，你建议先做什么。
```

## 通过标准

新窗口回答里应该包含：

- AI 工作台是多电脑、多 AI 窗口协作系统。
- 第一阶段是 GitHub + Markdown。
- MD 不是最终中心服务。
- 陈纪言负责共享 MD 系统底座。
- 肖明负责技能库正文。
- 历史证据、个人实验、待审核内容不能直接当正式规则。
- 后续要做独立新窗口实测、GitHub 上线或肖明技能库最小版本。
