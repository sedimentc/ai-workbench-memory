# 导入资料

本目录保存从本机导入的项目 MD/TXT 资料。

| 子目录 | 用途 |
| --- | --- |
| `项目资料/` | 普通项目说明、交接文档、README |
| `受限资料/` | 可能包含账号、密码、token、服务器信息的核心成员资料 |

导入资料默认不直接成为正式规则，需要整理成 `05_待审核/` 提案后再合并。
