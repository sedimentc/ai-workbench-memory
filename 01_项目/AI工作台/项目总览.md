# 项目总览：AI工作台

AI 工作台的目标是让刘大在一个统一页面里管理多台电脑、多种 AI 工具和多个对话窗口，减少来回切电脑、反复解释上下文、人工验收困难的问题。

## 项目目标

- 在一个页面查看多个电脑和窗口的任务状态。
- 能给不同电脑的不同 AI 窗口发送消息。
- 能稳定抓取窗口回复。
- 能看到哪些任务正在进行、哪些待提交、哪些卡住。
- 能通过共享记忆让新窗口快速接手。
- 能通过测试 Agent / DoneGuard 减少假完成。

## 相关系统

| 系统 | 说明 |
| --- | --- |
| Dashboard | 刘大任务中枢和工作台入口 |
| AI Workbench | 多电脑、多窗口观察和调度 |
| 公共 MD | 第一版共享记忆和规则出口 |
| DoneGuard | 测试 Agent / 独立验收基础 |

## 当前样板用途

本项目作为共享 MD 系统第一版样板，用来验证：

- 新窗口能否通过 Start Pack 接手。
- 项目事实和历史证据能否分离。
- 页面编号和资源登记能否不冲突。
- DoneGuard 能否接入测试 Agent 流程。
