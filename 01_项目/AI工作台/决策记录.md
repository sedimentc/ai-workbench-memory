# 决策记录：AI工作台

## DECISION-20260519-001：第一版采用 GitHub + Markdown

结论：第一版共享系统采用 GitHub + Markdown，先跑通协作、审核、项目接手和资源登记。

原因：Git 有版本记录、分支、审核和回退能力，适合团队第一阶段落地。

影响：资源发号和窗口状态暂时不做复杂中心服务。

## DECISION-20260519-002：MD 不是最终运行态中心

结论：MD 是人和 AI 都能读的协作层，后续运行态迁移到中心服务或数据库。

原因：页面角标、端口、窗口心跳、资源锁等靠 MD 长期管理会不稳定。

## DECISION-20260519-003：技能库由肖明负责

结论：本仓库保留 `02_技能库/`，但技能内容由肖明维护。

原因：陈纪言负责共享 MD 系统底座，肖明负责技能共享库和提示词效果测试。
