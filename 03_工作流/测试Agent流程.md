# 测试Agent流程

本流程描述测试 Agent 的系统位置，不替代肖明负责的技能库正文。

## 目标

解决 AI 主任务“看起来做完了但实际没完成”的问题，尤其是页面显示、按钮交互、数据一致性、接口返回和写入后读回。

## 角色

| 角色 | 责任 |
| --- | --- |
| 主任务 AI | 实现功能或修改页面 |
| 测试方案 AI | 根据需求生成测试清单 |
| 人工 | 审核测试清单，删改或批准 |
| 测试执行 AI | 按批准后的清单独立验收 |

## 和 DoneGuard 的关系

DoneGuard 已经实现了“测试方案、人工确认、独立验收、证据报告”的基本流程。页面30或测试 Agent 可以复用 DoneGuard 的思想和部分文件结构。

## 第一版重点

- 页面是否打开。
- 关键元素是否显示。
- 按钮是否能点击。
- 数据是否和来源窗口或接口一致。
- 修改后是否有截图或读回证据。
- 验收报告是否明确 pass / fail / partial。

## 禁止

- 不要让主任务 AI 自己证明自己完成。
- 不要未审核测试清单就自动执行高风险写入。
- 不要没有证据就标记通过。
