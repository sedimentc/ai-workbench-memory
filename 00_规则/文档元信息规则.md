# 文档元信息规则

正式文档必须包含 YAML 头部，方便 AI 和脚本判断状态、负责人、适用范围和敏感等级。

## 标准头部

```markdown
---
id: PROJ-AIW-001
type: project_state
status: current
owner: 陈纪言
reviewer: 刘大/老王/肖明
scope: AI工作台
sensitivity: internal
last_reviewed: 2026-05-19
source: 会议/人工确认/实践验证
---
```

## 字段说明

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` | 是 | 全局唯一编号 |
| `type` | 是 | 文档类型 |
| `status` | 是 | 生命周期状态 |
| `owner` | 是 | 维护人 |
| `reviewer` | 建议 | 审核人 |
| `scope` | 是 | 适用范围 |
| `sensitivity` | 是 | 敏感等级 |
| `last_reviewed` | 是 | 最近复核日期 |
| `source` | 是 | 来源 |

## 敏感等级

| 等级 | 含义 |
| --- | --- |
| `internal` | 团队内部可见，不应记录真实密码、token、API key |
| `restricted` | 少数核心成员受限可见，可在明确授权下记录真实协作凭据 |

如果文档需要记录真实凭据，必须额外增加：

```yaml
credential_allowed: true
```

没有这个字段的文档，即使是内部文档，也默认不能记录真实凭据。
