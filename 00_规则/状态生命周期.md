# 状态生命周期

每篇文档和每条规则都要有状态，避免 AI 把草稿、旧规则、被拒绝内容当成当前事实。

## 状态定义

| 状态 | 含义 | AI 是否可当正式依据 |
| --- | --- | --- |
| `draft` | 草稿 | 否 |
| `proposed` | 待审核 | 否 |
| `current` | 当前有效 | 是 |
| `recommended` | 推荐使用 | 是 |
| `deprecated` | 已废弃 | 否 |
| `rejected` | 已拒绝 | 否 |
| `conflict` | 存在冲突 | 否，需人工判断 |

## 替代规则

旧规则被新规则替代时，不要直接删除。应改为 `deprecated`，并在文档头部或正文写明 `replaced_by`。

## 证据和事实分离

会议记录、聊天摘要、历史尝试属于证据层。只有经过确认后，才能沉淀到 `当前状态.md` 或正式规则里。
