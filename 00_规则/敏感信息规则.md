# 敏感信息规则

共享 MD、技能库、待审核提案和历史证据中不得保存真实敏感信息。

## 禁止写入

- 真实密码。
- API key。
- token。
- cookie。
- 私钥。
- 个人隐私。
- 外部敏感承诺。

## 允许写入

可以写敏感信息引用，不写真实值。

示例：

```text
secret://mac0/keychain/openclaw/github-token
secret://computer1/env/DEEPSEEK_API_KEY
secret://liuda/private-channel/dashboard-password
```

## AI 处理规则

AI 发现用户提供了真实敏感信息时，不应写入共享文档。可以写成“密码走私密渠道”或 `secret://...` 引用。

## 审核规则

合并 PR 前必须运行 `scripts/check_memory_repo.py`。如发现疑似密钥、密码或 token，必须先处理再合并。
